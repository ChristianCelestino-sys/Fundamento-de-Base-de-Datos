# 📚 Fundamentos de Bases de Datos

Bienvenido a mi repositorio de la asignatura **Fundamentos de Bases de Datos**, donde se recopilan las actividades, diagramas, documentos técnicos y scripts SQL desarrollados durante el curso.

El repositorio presenta las diferentes etapas del diseño de bases de datos, desde los conceptos fundamentales y el modelo Entidad-Relación hasta la normalización y la implementación de esquemas en un Sistema Gestor de Bases de Datos (SGBD).

---

## 🎯 Objetivo del repositorio

Organizar y documentar las actividades realizadas durante el curso, aplicando los conceptos de diseño, modelado, integridad y normalización de bases de datos mediante herramientas de diagramación y lenguajes de definición de datos.

## 📂 Contenido del repositorio

### 📘 Unidad 1: Fundamentos y arquitecturas de bases de datos

Estudio de los fundamentos, objetivos, modelos y arquitecturas de las bases de datos, incluyendo la arquitectura ANSI/SPARC y los componentes de un Sistema Gestor de Bases de Datos.

📁 [**Ir a la Unidad 1**](./Unidad%201/README.md)

### 📗 Unidad 2: Diseño de bases de datos con el modelo E-R

Desarrollo del diseño conceptual mediante el modelo Entidad-Relación y diagramas UML para representar entidades, atributos, relaciones y estructuras de información.

📁 [**Ir a la Unidad 2**](./Unidad%202/README.md)

### 📙 Unidad 3: Modelo relacional

Transformación del modelo Entidad-Relación a un esquema relacional, identificación de claves primarias y foráneas, aplicación de reglas de integridad y generación del esquema físico mediante SQL.

**Actividades:**
- [Tarea 3.1: Transformación de Modelo E-R a Esquema Relacional y Reglas de Integridad](./Unidad%203/Tarea%203.1/README.md)
- [Tarea 3.2: Generación del esquema físico en SGBD y script LDD](./Unidad%203/Tarea%203.2/README.md)

📁 [**Ir a la Unidad 3**](./Unidad%203/README.md)

### 📕 Unidad 4: Normalización de bases de datos

Estudio de las dependencias funcionales, las anomalías de actualización y las formas normales. Aplicación del proceso de normalización al proyecto TechMarket Express para mejorar la organización y la integridad de la información.

**Actividades:**
- [Tarea 4.1: Fundamentos de dependencias y mapa conceptual de formas normales](./Unidad%204/Tarea%204.1/README.md)
- [Tarea 4.2: Proceso paso a paso de normalización del proyecto aplicado](./Unidad%204/Tarea%204.2/README.md)

📁 [**Ir a la Unidad 4**](./Unidad%204/README.md)
