# 📚 Unidad 2: Diseño de Bases de Datos con el Modelo E-R

## 📌 Descripción
En esta unidad se estudia el diseño conceptual de bases de datos mediante el modelo Entidad-Relación (E-R) y su relación con la notación UML, aplicando conceptos de modelado para representar la estructura de un sistema.

## 🎯 Competencia
Conocer y aplicar el modelo Entidad-Relación (E-R) para el diseño conceptual de bases de datos.
