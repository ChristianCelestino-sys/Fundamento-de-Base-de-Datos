# 📗 Tarea 2.2. Transición del diagrama E-R a notación UML

## 📌 Descripción
En esta actividad se realiza la transformación de un diagrama Entidad-Relación (E-R) a un diagrama de clases UML, utilizando como base el modelo conceptual desarrollado en la Tarea 2.1.

## 🎯 Objetivo
Representar el modelo conceptual de una base de datos mediante la notación UML, identificando las clases, sus atributos y las relaciones entre ellas.

## 📝 Actividades
- Retomar el diagrama E-R elaborado en la Tarea 2.1.
- Convertir las entidades en clases UML.
- Transformar los atributos en propiedades de las clases.
- Representar las relaciones mediante asociaciones.
- Identificar relaciones de composición, agregación y herencia cuando corresponda.
- Elaborar el diagrama de clases UML.
- Analizar las diferencias entre el modelo E-R y UML.
- Explicar cómo se relaciona el diseño de bases de datos con la programación orientada a objetos.
