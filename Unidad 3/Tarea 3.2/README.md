# Tarea 3.2: Generación del esquema físico en SGBD y script LDD

## 📌 Descripción

En esta actividad se realizará la implementación del esquema físico de una base de datos a partir del modelo relacional desarrollado en la Unidad 3. Se utilizará un Sistema Gestor de Bases de Datos (SGBD) para crear las tablas, definir sus restricciones de integridad y comprobar el funcionamiento del script del Lenguaje de Definición de Datos (LDD).

El proyecto estará basado en el caso de estudio **TechMarket Express**, considerando la estructura de las tablas, las claves primarias, las claves foráneas y las restricciones necesarias para mantener la integridad de los datos.

## 🎯 Objetivo

Implementar el esquema físico de una base de datos mediante un SGBD, utilizando instrucciones SQL del Lenguaje de Definición de Datos (LDD) para crear tablas y establecer restricciones de integridad.

## 📚 Contenido de la actividad

La actividad contempla los siguientes aspectos:

- Implementación del esquema físico de la base de datos.
- Creación de tablas mediante instrucciones `CREATE TABLE`.
- Definición de claves primarias (`PRIMARY KEY`).
- Definición de claves foráneas (`FOREIGN KEY`).
- Aplicación de restricciones `NOT NULL` y `CHECK`.
- Configuración de acciones de actualización y eliminación, como `ON UPDATE` y `ON DELETE`, cuando corresponda.
- Validación y ejecución del script SQL.
- Generación del diccionario de datos.
- Elaboración del diagrama físico de la base de datos.
- Evidencias de ejecución en el SGBD.

## 🛠️ Herramientas utilizadas

- **Sistema Gestor de Bases de Datos (SGBD):** PostgreSQL, MySQL/MariaDB o SQL Server.
- **SQL:** Lenguaje utilizado para definir la estructura de la base de datos.
- **GitHub:** Repositorio para documentar y publicar los archivos de la actividad.
- **Draw.io:** Herramienta para elaborar o ajustar diagramas.
- **PDF:** Formato para presentar el reporte y el diccionario de datos.

## 📁 Entregables

Los archivos de esta actividad se organizarán de la siguiente manera:

- **Script SQL:** archivo con las instrucciones LDD para crear las tablas y definir sus restricciones.
- **Reporte PDF:** documento con la descripción de la implementación y el diccionario de datos.
- **Diagrama del esquema físico:** representación de las tablas, atributos, claves y relaciones.
- **Evidencias de ejecución:** capturas que demuestren la creación y validación de la base de datos.
- **Video de exposición:** explicación del proceso de implementación y demostración del funcionamiento del script.
