# 📚 Unidad 5: Álgebra relacional

## 📌 Descripción

En esta unidad se estudia el álgebra relacional como lenguaje formal para consultar y manipular información en bases de datos. Se analizan sus operadores fundamentales y extendidos, así como su aplicación en la resolución de consultas sobre esquemas relacionales.

También se desarrolla un catálogo de consultas utilizando expresiones formales de álgebra relacional aplicadas al proyecto TechMarket Express.

## 🎯 Competencia

Aplica operadores de álgebra relacional básica y extendida para acceder a la información de bases de datos.

En este repositorio se encuentran los materiales, documentos y recursos correspondientes a las actividades de la Unidad 5.
