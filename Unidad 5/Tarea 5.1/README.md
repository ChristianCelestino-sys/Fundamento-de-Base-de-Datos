# 📘 Tarea 5.1: Operadores fundamentales y extendidos del álgebra relacional

## 📌 Descripción

En esta actividad se estudian los operadores fundamentales y extendidos del álgebra relacional, los cuales permiten realizar consultas y operaciones sobre los datos de una base de datos relacional. Se explica su funcionamiento mediante ejemplos y representaciones gráficas.

## 🎯 Objetivo

Identificar y comprender los operadores del álgebra relacional, así como aplicar sus operaciones para consultar, combinar, filtrar y organizar información de una base de datos.

## 📂 Contenido de la actividad

En esta carpeta se encuentran los materiales, diagramas y documentos correspondientes a la Tarea 5.1.

- **Documento PDF:** Desarrollo teórico y ejemplos de los operadores del álgebra relacional.
- **Diagrama conceptual:** Representación gráfica de los operadores.
- **Ejemplos prácticos:** Aplicación de las operaciones sobre relaciones de una base de datos.

## 📚 Temas desarrollados

- Concepto de álgebra relacional.
- Selección (σ).
- Proyección (π).
- Unión (∪).
- Diferencia (−).
- Producto cartesiano (×).
- Renombramiento (ρ).
- Intersección (∩).
- Reunión o combinación (⋈).
- División (÷).
- Operadores extendidos y funciones de agregación.
